This section covers the categorization of pronouns in Tsakonian, primarily based on the systematic tables provided by [[Condensed Grammar of the Tsakonian Language in Tables.md|(García Chaparro, 2023)]].

### Personal Pronouns

Tsakonian personal pronouns distinguish between strong (emphatic) and weak (clitic) forms.

| Person       | Case      | Singular Strong | Singular Weak | Plural Strong                   | Plural Weak      |
| :----------- | :-------- | :-------------- | :------------ | :------------------------------ | :--------------- |
| **1st (A')** | **Nom.**  | εζού / εζούνε   |               | ενεί                            |                  |
|              | **Gen.**  |                 |               |                                 | νάμου            |
|              | **Acc.**  |                 | μι            | εμού / εμούνε / ενείνανε        | νάμου / νάμι     |
|              | **Prep.** | ενίου           |               | εμού / εμούνε / ενείνανε / ενεί |                  |
| **2nd (B')** | **Nom.**  | εκιού / εκiούνε |               | εμού                            |                  |
|              | **Gen.**  |                 |               |                                 | νιούμου          |
|              | **Acc.**  |                 | ντι           | εμού / εμούνε                   | νιούμου / νιούμι |
|              | **Prep.** | ετίου           |               |                                 |                  |
| **3rd (Γ')** | **Gen.**  |                 | σι            |                                 | σου              |
|              | **Acc.**  |                 | νι            |                                 | σι               |

### Demonstrative Pronouns

| Meaning        | Masculine (S/P) | Feminine (S/P) | Neuter (S/P)    |
| :------------- | :-------------- | :------------- | :-------------- |
| **This**       | Έντενη / Έντεοι | Έντανη / -     | Έγκεινι / Ένται |
| **That**       | Ετήνε / Ετήνοι  | Ετήνα / -      | Έκεινι / Έκεινι |
| **That (Far)** | Άλλε / Άλοι     | Άβα / -        | Άλλιου / Άβα    |
