# 5.3 Adjectives, Pronouns, and Numbers

This section covers the declension and categorization of adjectives, pronouns, and numerals in Tsakonian, primarily based on the systematic tables provided by [[Condensed Grammar of the Tsakonian Language in Tables.md|(García Chaparro, 2023)]].

## Adjectives

Tsakonian adjectives are classified into several types based on their gender-specific endings and declension patterns.

| Type   | Nom. / Acc. (Masc.) | Nom. / Acc. (Fem.) | Nom. / Acc. (Neut.) | Genitive (M/N) | Plural (M) | Plural (F) | Plural (N) |
| :----- | :------------------ | :----------------- | :------------------ | :------------- | :--------- | :--------- | :--------- |
| **Ε1** | -ε                  | -α                 | -ε                  | -ου            | -οι        | -α         | -α         |
| **Ε5** | -ο                  | -α                 | -ο                  | -ου            | -οι        | -α         | -α         |
| **Ε2** | -ε                  | -α                 | -ιου                | -ε             | -οι        | -α         | -α         |
| **Ε3** | -ε                  | -ε                 | -ιου                | -ε             | -οι        | -α         | -α         |
| **Ε6** | -ε                  | -ο                 | -ε                  | -ου            | -οι        | -οι        | -α         |
| **Ε7** | -ιού                | -ία                | -ιού                |                | -οί        | -ίε        | -ία        |
| **Ε8** | -η                  | -α                 | -ικο                | -ικου          | -ηδε       | -ε         | -ικα       |
| **Ε4** | -ε                  | -ε                 | -ιου                |                | -οι        | -α         | -α         |

## Pronouns

### Personal Pronouns

Tsakonian personal pronouns distinguish between strong (emphatic) and weak (clitic) forms [[Condensed Grammar of the Tsakonian Language in Tables.md|(García Chaparro, 2023)]].

| Person       | Case      | Singular Strong | Singular Weak | Plural Strong                   | Plural Weak      |
| :----------- | :-------- | :-------------- | :------------ | :------------------------------ | :--------------- |
| **1st (A')** | **Nom.**  | εζού / εζούνε   |               | ενεί                            |                  |
|              | **Gen.**  |                 |               |                                 | νάμου            |
|              | **Acc.**  |                 | μι            | εμού / εμούνε / ενείνανε        | νάμου / νάμι     |
|              | **Prep.** | ενίου           |               | εμού / εμούνε / ενείνανε / ενεί |                  |
| **2nd (B')** | **Nom.**  | εκιού / εκιούνε |               | εμού                            |                  |
|              | **Gen.**  |                 |               |                                 | νιούμου          |
|              | **Acc.**  |                 | ντι           | εμού / εμούνε                   | νιούμου / νιούμι |
|              | **Prep.** | ετίου           |               |                                 |                  |
| **3rd (Γ')** | **Gen.**  |                 | σι            |                                 | σου              |
|              | **Acc.**  |                 | νι            |                                 | σι               |

### Demonstrative Pronouns

| Meaning        | Masculine (S/P) | Feminine (S/P) | Neuter (S/P)    |
| :------------- | :-------------- | :------------- | :-------------- |
| **This**       | Έντενη / Έντεοι | Έντανη / -     | Έγκεινι / Ένται |
| **That**       | Ετήνε / Ετήνοι  | Ετήνα / -      | Έκεινι / Έκεινι |
| **That (Far)** | Άλλε / Άλοι     | Άβα / -        | Άλλιου / Άβα    |

### Other Pronouns

| Meaning       | Masculine (S/P)        | Feminine (S/P)             | Neuter (S/P)         |
| :------------ | :--------------------- | :------------------------- | :------------------- |

| **All**       | Όλε                    | Όα                         | Όλιου                |
