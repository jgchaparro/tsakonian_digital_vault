# Tsakonian Orthography

The Tsakonian language lacks a single, widely accepted orthographic consensus. Because Tsakonian contains phonemes not present in Standard Modern Greek (SMG)—such as aspirated consonants, postalveolar fricatives, and specific affricates—scholars and speakers have developed various systems to represent these sounds using the Greek alphabet, often supplemented by diacritics or digraphs. [[Learn Tsakonian Orthography.md|(García Chaparro, 2026)]]

## 1. The Tsakonian Alphabet

Tsakonian uses the standard Greek alphabet with additional rules and readings for certain clusters. [[Learn Tsakonian Orthography.md|(García Chaparro, 2026)]]

### Accentuation
Accent marks indicate the stressed syllable and must be marked in all words except monosyllables (e.g., **εζού** 'I', but **ναι** 'yes'). [[Learn Tsakonian Orthography.md|(García Chaparro, 2026)]]

## 2. Historical and Academic Systems

### Early Records (17th - 18th Century)

- **Evliyâ Çelebi (1668):** Ottoman Turkish script. [[Tsakonian Studies State of the Art.md|(Liosis, 2017)]]
- **Villoison (1788):** Brief recordings. [[Tsakonian Studies State of the Art.md|(Liosis, 2017)]]

### 19th Century Systematic Grammars

- **Oikonomou (1846, 1870):** Used **κχ**, **τθ**, **πφ** for aspirates. [[Simple Kostakis Orthography Proposal.md|(García Chaparro, 2025c)]]
- **Michael Deffner (1881, 1923):** Introduced diacritics for aspirates, postalveolars, and palatals. [[Simple Kostakis Orthography Proposal.md|(García Chaparro, 2025c)]]

### 20th Century: The Kostakis Standard

**Thanasis Kostakis (1951, 1986):** Refined Deffner's system using diacritics. It is used in the *Dictionary of the Tsakonian Dialect*. [[Tsakonian Studies State of the Art.md|(Liosis, 2017)]]

| Letter  | Sound | Tsakonian    | English           |
| :------ | :---- | :----------- | :---------------- |
| **κ̔**  | [kʰ]  | **κ̔αρα**    | fire              |
| **τ̔**  | [tʰ]  | **τ̔αίνου**  | lift              |
| **π̔**  | [pʰ]  | **επ̔έρι**   | yesterday         |
| **σ̌**  | [ʃ]   | **σ̌ίνα**    | mountain          |
| **ζ̌**  | [ʒ]   | **κάζ̌υ**    | walnut            |
| **τσ̑** | [t ̻͡ s̪] | **τσ̑αι**    | and               |
| **τζ̑** | [d͡z] | **τζ̑αμοζ̌άζου**    | put something in a precarious position               |
| **ν̇**  | [n]   | **έν̇ι**     | he is             |
| **λ̣**  | [l]   | **λ̣ίμνα**   | lake              |
| **ν̂**  | [ɲ]   | **ν̂’επέκα** | I told him/her/it |
| **α̈** | [ä] | **δα̈δά** | now (Propontis) |

**Special Characters for Propontis Tsakonian:**
In his 1951 grammar, Kostakis introduced additional diacritics to represent unique phonetic developments in the Propontis dialect [[Kostakis Short Grammar of Tsakonian 1951.md|(Kostakis, 1951)]]:

**Palatalization Rules in Kostakis:**
- **ν** and **λ** are palatalized ([ɲ], [ʎ]) before [i] sounds (**ι, υ, ει, οι...**).
- **ν̇** and **λ̣** indicate *non-palatalized* sounds in environments where they would normally be palatalized. [[Simple Kostakis Orthography Proposal.md|(García Chaparro, 2024)]]
- **ν̂** represents a palatalized [ɲ] resulting from contraction, often appearing as **ν̂'** before a vowel. [[Simple Kostakis Orthography Proposal.md|(García Chaparro, 2024)]]

## 3. Modern and Digital Orthographies

### Marneris' Orthography (2024)
Developed by Panos Marneris to simplify typing by using digraphs and the letter **h**. [[Learn Tsakonian Orthography.md|(García Chaparro, 2026)]]

| Sound            | Representation | Notes                                            |
| :--------------- | :------------- | :----------------------------------------------- |
| [kʰ], [tʰ], [pʰ] | **κχ, τθ, πφ** | Uses historical digraphs.                        |
| [ʃ], [ʒ]         | **σh, ζh**     | Uses **h** to indicate postalveolar.             |
| [ɲi]             | **ννι**        | Represents palatalization with double consonant. |
| [ni]             | **νι**         | Does not distinguish from non-palatalized [ni].  |
| [li] / [ʎi]      | **λι**         | Does not distinguish between **λι** vs **λ̣ι**.  |

### Simple Kostakis (2025)
Proposed by Jaime García Chaparro as a bridge using digraphs and trigraphs while maintaining a one-to-one correspondence with Kostakis' system for digital accessibility. It synthesizes elements from academic precision and practical digraph-based models [[Simple Kostakis Orthography Proposal.md|(García Chaparro, 2024)]].

**Core Mapping:**

| Sound  | Kostakis | Simple Kostakis |
| ------ | -------- | --------------- |
| /kʰ/   | **κ̇**   | **κχ**          |
| /tʰ/   | **τ̇**   | **τθ**          |
| /pʰ/   | **π̇**   | **πφ**          |
| /ʃ/    | **σ̌**   | **ξξ**          |
| /ʒ/    | **ζ̌**   | **ζζ**          |
| [t͡s̻] | **τσ̂**  | **τσσ**         |
| [ADD]  | **τζ̑**  | **τσζ**         |
| /ni/   | **ν̇ι**  | **ν'ι**         |
| /ɲi/   | **νι**   | **νι**          |
| /ɲ/    | **ν̂**   | **νι'**         |
| /li/   | **λ̣ι**  | **λ'ι**         |
| /ʎi/   | **λι**   | **λι**          |
| /ä/    | **α̈**   | **α'**          |

**Affricate Distinction:**
Simple Kostakis maintains the contrast between the standard affricate **τσ** [ts] and the laminal dental affricate **τσσ** [t͡s̻] (Kostakis' **τσ̂**). This distinction is often merged in other modern proposals but preserved here for linguistic consistency [[Simple Kostakis Orthography Proposal.md|(García Chaparro, 2024)]].
